# Ava Player (آوا پلیر) 🎵✨

موزیک پلیر مدرن، فوق‌العاده زیبا و هوشمند با رابط کاربری نئونی دارک (Jetpack Compose & Material Design 3).

## ویژگی‌های اصلی (Key Features)

- 🔍 **اسکن خودکار و هوشمند حافظه**: شناسایی خودکار تمام آهنگ‌های دستگاه از طریق MediaStore و جستجوی دایرکتوری‌های حافظه داخلی (`Music`، `Download`، `Telegram` و...).
- 📂 **انتخاب پوشه دلخواه (SAF Folder Picker)**: امکان انتخاب هر پوشه دلخواه یا کارت حافظه برای ایندکس و پخش آهنگ‌ها.
- 📜 **پشتیبانی کامل از متن ترانه همگام (LRC Parser)**:
  - خواندن خودکار فایل‌های `.lrc` هم‌نام در کنار فایل‌های صوتی
  - اسکرول خودکار و همگام با زمان پخش آهنگ
  - هایلایت نئونی خط فعال ترانه
  - امکان ضربه روی هر خط ترانه برای پرش مستقیم به آن ثانیه
  - ویرایشگر اختصاصی برای اضافه یا ویرایش دستی متن‌های LRC
- 💽 **صفحه گرامافون واقعی (Vinyl Turntable)**:
  - دیسک چرخان وینیل با شیارهای واقعی و بازتاب نور
  - بازوی متحرک گرامافون (Tone-arm) که هنگام پخش روی صفحه قرار می‌گیرد و با توقف به جای خود برمی‌گردد.
- 📊 **ویژوالایزر صوتی واکنش‌پذیر**:
  - حالت ستون‌های نئونی (Spectrum Bars)
  - حالت موج سینوسی درخشان (Neon Wave)
  - حالت پالس شعاعی و ذرات مداری (Radial Pulse)
- 🎚️ **اکولایزر ۵ بانده پیشرفته (Graphic Equalizer)**:
  - پریست‌های صوتی آماده (Rock, Pop, Bass, Jazz, Electronic, Classical, Flat)
  - تقویت بیس (Bass Boost)
  - صدای فراگیر و سه‌بعدی (3D Virtualizer Surround)
- 🎛️ **مینی پلیر شناور فوق‌العاده جذاب (Floating Mini Player)**:
  - طراحی شیشه‌ای (Glassmorphism) با کادر درخشان گرادیانت نئون
  - نوار باریک پیشرفت زمان پخش
  - مینی دیسک چرخان
  - دکمه‌های کنترل سریع (قبلی، پخش/توقف، بعدی، علاقه‌مندی)
- 🗂️ **مدیریت پلی‌لیست‌ها و لیست‌های هوشمند**:
  - لیست آهنگ‌های برگزیده (Favorites)
  - لیست اخیراً پخش‌شده (Recently Played)
  - ساخت و مدیریت پلی‌لیست‌های اختصاصی
- ⏱️ **تایمر خواب هوشمند (Sleep Timer)** با شمارش معکوس و پریست‌های متنوع
- 💾 **پایگاه داده ماندگار محلی (SQLite & Repository Pattern)** برای ذخیره وضعیت‌ها، آمار پخش و پلی‌لیست‌ها.

## نصب و دانلود فایل برنامه (Installation & APK)

فایل نصبی آماده برنامه در مسیر زیر قرار گرفته است:
- `release/AvaPlayer-v1.0.apk`
- همچنین از مسیر پیش‌فرض بیلد: `app/build/outputs/apk/debug/app-debug.apk`

### مشخصات نسخه (Version Info)
- **نسخه برنامه (Version Name)**: `1.0.0 (Release 1.0)`
- **کد نسخه (Version Code)**: `1`
- **حداقل نسخه اندروید (minSdk)**: Android 7.0 (API 24)
- **نسخه هدف (targetSdk)**: Android 15 / 16 (API 36)
- **زبان**: Kotlin + Jetpack Compose
